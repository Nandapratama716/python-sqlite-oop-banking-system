# Python SQLite OOP Banking System

A simple banking system built with Python, SQLite, and Object-Oriented Programming.

## About

This project is part of my Full Stack AI Engineer learning journey.

The goal of this project is to practice:

- Python OOP
- SQLite database integration
- Repository pattern
- Service layer
- Basic banking transactions
- Clean project structure

- Customer management
- Savings and current accounts
- Deposit
- Withdraw
- Transfer
- Transaction history

## Tech Stack

- SQLite
- sqlite3
- Object-Oriented Programming
